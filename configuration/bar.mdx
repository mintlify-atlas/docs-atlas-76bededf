The Serpantinum bar is a single panel that can dock to any screen edge. It is divided into three independent module zones — left, center, and right — and supports three distinct visual styles that change how the background is rendered. All bar settings live under the `"bar"` key in `~/.config/serpantinum/settings.json` and are hot-reloaded at runtime.

## Parameters

<ParamField path="bar.position" type="string" default="top">
  Which screen edge the bar docks to.

  **Accepted values:** `"left"` | `"right"` | `"top"` | `"bottom"`
</ParamField>

<ParamField path="bar.width" type="integer" default="100">
  Bar thickness in pixels. Has no effect when `style` is `"fill"` because fill mode stretches the bar to 100 % of the edge.

  Must be a positive integer.
</ParamField>

<ParamField path="bar.opacity" type="integer" default="100">
  Background opacity of the bar, expressed as a percentage.

  **Range:** `0` – `100`
</ParamField>

<ParamField path="bar.style" type="string" default="fill">
  Visual style of the bar background.

  | Value | Effect |
  |---|---|
  | `"modular"` | Each module group renders as a distinct floating pill |
  | `"solid"` | A single solid rectangle spans the full bar width |
  | `"fill"` | Full-width, full-height fill that extends edge to edge |
</ParamField>

<ParamField path="bar.autohide" type="boolean" default="false">
  When `true`, the bar slides off-screen when the pointer leaves it and reappears on hover.
</ParamField>

<ParamField path="bar.autohideTimeout" type="integer" default="1000">
  Milliseconds of cursor inactivity before the bar hides. Only active when `autohide` is `true`.

  **Range:** 250 – 10 000 ms
</ParamField>

<ParamField path="bar.workspaceCount" type="integer" default="8">
  Number of workspace indicators rendered in the `workspaces` module.

  **Range:** 2 – 10
</ParamField>

<ParamField path="bar.time.format" type="string" default="HH:mm:ss">
  Qt date-time format string used by the `timedate` module clock. Standard Qt format tokens apply — `HH` for 24-hour hours, `hh` for 12-hour, `mm` for minutes, `ss` for seconds, `AP` for AM/PM.

  Examples: `"HH:mm"`, `"hh:mm AP"`, `"HH:mm:ss"`
</ParamField>

<ParamField path="bar.groupColors" type="object" default="{}">
  Per-group accent colour overrides. Keys are group IDs (auto-generated as `g_<firstModuleId>`) and values are hex colour strings. The bar assigns accent colours automatically from the active theme palette; use this object to pin specific groups to specific colours.

  ```json
  "groupColors": {
    "g_kb": "#96cdf8",
    "g_timedate": "#f9e2af"
  }
  ```
</ParamField>

<ParamField path="bar.modules.left" type="array" default='["left", "workspaces", "media"]'>
  Ordered list of modules rendered in the left zone. Each entry is either a bare module name string or a nested array of names that will be visually grouped together as a single pill.
</ParamField>

<ParamField path="bar.modules.center" type="array" default='[["timedate", "info", "weather"]]'>
  Ordered list of modules rendered in the center zone. Supports the same bare-string and nested-array syntax as `left`.
</ParamField>

<ParamField path="bar.modules.right" type="array" default='["tray", ["kb", "wifi", "bt", "vol", "bat"]]'>
  Ordered list of modules rendered in the right zone. Supports the same bare-string and nested-array syntax as `left`.
</ParamField>

## Module grouping syntax

Modules placed inside a nested array are rendered as a single pill with a shared accent colour. Modules at the top level are standalone pills.

```json
"modules": {
  "left": ["left", "workspaces", "media"],
  "center": [
    ["timedate", "info", "weather"]
  ],
  "right": [
    "tray",
    ["kb", "wifi", "bt", "vol", "bat"]
  ]
}
```

In the example above, `timedate`, `info`, and `weather` form one grouped pill in the center, while `kb` through `bat` form another grouped pill on the right. `tray` remains a standalone module.

<Tip>
  Right-click any module chip inside the guide's bar configuration panel to start grouping: right-click the first module, then right-click the target module. The two are merged into a single pill and assigned an accent colour from your active palette. Right-click an already-grouped module to ungroup it.
</Tip>

## Full example

```json
"bar": {
  "position": "top",
  "width": 100,
  "opacity": 95,
  "style": "modular",
  "time": {
    "format": "HH:mm"
  },
  "autohide": false,
  "autohideTimeout": 1000,
  "workspaceCount": 8,
  "groupColors": {
    "g_kb": "#96cdf8"
  },
  "modules": {
    "left": ["left", "workspaces", "media"],
    "center": [
      ["timedate", "info", "weather"]
    ],
    "right": [
      "tray",
      ["kb", "wifi", "bt", "vol", "bat"]
    ]
  }
}
```

<Tip>
  Open the guide popup from the bar's action button and navigate to the **Bar** tab for a live drag-and-drop module editor. Changes are previewed instantly without restarting the shell.
</Tip>

For documentation on the widgets that individual modules render, see [Bar Widgets](/features/bar-widgets).
