Serpantinum stores all its configuration in a single JSON file at `~/.config/serpantinum/settings.json`. Every option you set through the in-app guide popup is immediately written back to this file, so you can edit it directly in a text editor or manage it through NixOS Home Manager — both approaches produce identical results.

## Configuration file location

The file is read on startup and hot-reloaded whenever it changes on disk. If the file does not exist, Serpantinum creates it automatically with the defaults shown below.

```bash
~/.config/serpantinum/settings.json
```

## How the in-app guide writes settings

Opening the guide popup (accessible from the bar's action button) provides a live GUI for every setting. Changes take effect instantly — the guide calls `Config.setSetting()` internally, which writes the merged object back to `settings.json` without a restart. You can have the file open in your editor at the same time and watch it update in real time.

<Note>
  The guide and the JSON file are always in sync. Any manual edit you make to `settings.json` is picked up on the next file-system watch event, typically within a second.
</Note>

## Top-level sections

| Section | Description | Reference |
|---|---|---|
| `general` | Language, avatar path, UI sound effects, weather refresh interval and units | *(general settings)* |
| `bar` | Position, style, opacity, autohide, clock format, and the three module arrays | [Bar](/configuration/bar) |
| `theme` | Font family, border radius, active color preset, and Matugen toggle | [Theme](/configuration/theme) |
| `idle` | Master switch, four built-in idle actions (dim / DPMS / lock / suspend), and custom actions | [Idle](/configuration/idle) |
| `notifications` | Do-Not-Disturb flag, popup corner position, and notification sound | [Notifications](/configuration/notifications) |
| `display` | Per-monitor blue-light filter, color temperature, and scale factor | [Display](/configuration/display) |

## NixOS / Home Manager

When you manage Serpantinum through the Home Manager module, the `settings` attribute set maps **1 : 1** to the keys in `settings.json`. Every option described in the sub-pages below can be expressed as a Nix attribute — the module serialises it to JSON for you.

```nix
programs.serpantinum.settings = {
  bar = {
    position = "top";
    style = "modular";
    opacity = 95;
  };
  theme = {
    fontFamily = "JetBrains Mono";
    borderRadius = 10;
    activePreset = "Nord";
    matugen = false;
  };
};
```
