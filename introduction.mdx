Serpantinum is a modern Wayland desktop shell built with [Quickshell](https://quickshell.outfoxxed.me/) and QML. It sits on top of your Wayland compositor and provides a polished, cohesive desktop experience — including a configurable status bar, desktop widgets, a notification daemon, an application launcher, a system panel, idle management, and a live theming engine — all driven by a single JSON configuration file. The current release is **v2.1.5**.

## Supported Compositors

Serpantinum ships with ready-made integration configs for three compositors. You can run it on any of them without writing compositor config from scratch.

## Architecture

Serpantinum uses a two-process model:

- **`serpantinumd`** — the supervisor daemon. It acquires a lock file at `/tmp/serpantinumd.lock`, writes its PID to `/tmp/serpantinumd.pid`, launches the wellbeing/idle helper, and starts the Quickshell process. It handles `start`, `stop`, and `status` subcommands and cleans up all child processes on exit.
- **`quickshell`** — the QML runtime that renders the bar, widgets, notifications, and every visible element. It is managed entirely by `serpantinumd` and should not be launched directly during normal use.

The **`serpantinum`** CLI communicates with the running shell over a socket, forwarding workspace switches, panel toggles, IPC calls, and script helpers (lock, screenshot, brightness, volume, etc.) without restarting the daemon.

```
┌─────────────────────────────────────────┐
│  serpantinumd  (supervisor, PID file)   │
│    ├─ wellbeing/launch_daemon.sh        │
│    └─ quickshell -p Shell.qml           │
└─────────────────────────────────────────┘
         ▲
         │  IPC socket
         │
   serpantinum msg / ipc / …
```

<Note>
  Serpantinum currently supports **Arch Linux and its derivatives** via the automated installer. A NixOS flake is also provided with a NixOS module and a Home Manager module. Other distributions are not supported by the automated installer.
</Note>
