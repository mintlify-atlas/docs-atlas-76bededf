Serpantinum is a modern desktop shell for Wayland compositors, built on top of [Quickshell](https://quickshell.outfoxxed.me/) and QML. It delivers a polished bar, draggable desktop widgets, a full notification center, app launcher, system panel, and deep theming — all configurable through a single `settings.json` or a built-in graphical guide.

## Quick Start

<Steps>
  <Step title="Install (Arch Linux)">
    Run the automated installer — it detects your compositor and installs all required packages:
    ```bash
    bash -c "$(curl -fsSL https://raw.githubusercontent.com/ilyamiro/serpantinum/master/install/install.sh)"
    ```
  </Step>
  <Step title="Start the shell">
    Launch the daemon which manages the Quickshell process:
    ```bash
    serpantinumd start
    ```
  </Step>
  <Step title="Open the settings guide">
    The built-in graphical guide lets you configure everything without editing files:
    ```bash
    serpantinum msg open guide
    ```
  </Step>
  <Step title="Customize further">
    Edit `~/.config/serpantinum/settings.json` directly or explore the [Configuration](/configuration/overview) section for all available options.
  </Step>
</Steps>

<Note>
  Serpantinum currently supports **Arch Linux and its derivatives** for the automated installer. NixOS users can use the provided flake — see [NixOS Installation](/nix-installation).
</Note>
